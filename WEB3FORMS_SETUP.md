# Web3Forms Quick Setup Guide

## 1. Get Your Access Key
Visit https://web3forms.com and sign up with **info@dualsyncagency.com**

## 2. Add to .env.local
```bash
VITE_WEB3FORMS_ACCESS_KEY=your_actual_key_here
```

## 3. Restart Server
```bash
npm run dev
```

## 4. Test Form
Navigate to `/contact` and submit a test message.

Check **info@dualsyncagency.com** for the email!

---

**Email Target:** info@dualsyncagency.com  
**Form Fields:** Name, Email, Project Type, Message
